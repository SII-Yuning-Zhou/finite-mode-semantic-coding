## 选择哪个 DOI

复现或引用本版本时，使用上述 **版本 DOI**。需要指向整个项目的全部归档版本时，
可使用 [Concept DOI：10.5281/zenodo.23774112](https://doi.org/10.5281/zenodo.23774112)。

这是软件和复现材料的 DOI；论文发表后的期刊 DOI 单独引用。作者及版本引用格式
已写入根目录 `CITATION.cff`，代码与数据可用性声明见
[发布与引用说明](PUBLISHING_CHECKLIST_ZH.md)。

## 后续更新

当前 GitHub 文档可继续更新。已经归档的 `v1.0.0` ZIP 和固定 tag 保留原样；
发布新的代码／材料版本时，在同一 Zenodo 记录下选择 **New version**，归档新版本
并取得对应 DOI。更新版本信息及关联标识符后再归档，不重复创建同版本记录。
