# Figure and table reproduction

## Two complementary records

1. `figures/publication/fig1.pdf` through `fig6.pdf` are the exact vector PDFs
   used by manuscript V53. They were copied without modification. Corresponding
   PNGs are viewing previews. Fig. 1 is a fixed system schematic, not an empirical
   result; it is not regenerated by the numeric plotting command.
2. `reproduce/figures.py` is a portable **scientific replot**, not a claim of
   pixel-identical journal typesetting. It reads frozen numeric arrays from the
   accepted figure builders, not values digitized from a PDF. It retains the
   original curves, masks, line connections, point centers, confidence-interval
   paths, units, ranges, marker shapes, soft vector highlights and corner keys.
   Open DejaVu/STIX fonts are used, and Fig. 3 is slightly wider to accommodate
   open-font tick-label metrics. The exact publication appearance is preserved
   in the archived PDFs in item 1.

No local skill installation, absolute development path, PyTorch, CompressAI,
TeX installation, model checkpoint, or network access is needed for these
numeric replots. The requirements are NumPy and Matplotlib.

## Commands

From the repository root:

```sh
python -m reproduce.check_data --output outputs/data_checks.json
python -m reproduce.figures --output outputs/figures
python -m reproduce.tables --output outputs/tables
```

The figure command writes PDF, SVG and PNG for Figs. 2–6, plus
`replot_checks.json`. On the preparation Windows/CPU environment it completed
in roughly tens of seconds; this is not a benchmark promise for other machines.
Use `--figures 3 6` to render a subset. The source arrays are not fitted,
smoothed, interpolated, jittered, resampled or selected for favorable outcomes.

`check_data` parses strict standard JSON, verifies observation/CI inventories,
and matches all 6,309 positive phase-map entries against the original 20,402-row
CSV. `null` in a scene is a masked/non-finite original coordinate, not zero;
the renderer restores it as a masked value or a NaN line break.

## Table V from original endpoint profiles

RC2 includes the original eight endpoint profiling reports and their 80-row
resource ledger. `reproduce.tables` independently aggregates the reports,
checks the ledger and computes the four Table V summary ranges. It compares
those ranges with the separately retained **manuscript transcription**, with
`source_kind=manuscript_table_V_transcription_not_raw_profile`.

The table script checks positive timing ranges, min/max consistency, state
storage and CDF values against the measured profiles. It does not substitute
the v8.1 whole-audit `conditional_codec_seconds` column for batch-one endpoint
encode latency. Reaggregating the recorded timing sequences is distinct from
remeasuring latency on a new platform; see `NEURAL_REPRODUCTION.md`.

## Scene schema and provenance

The JSON schema is `finite-mode-frozen-scientific-scene-v1`. Each figure records
its source physical canvas, axes limits/scales/ticks/labels, complete numeric
line arrays, mesh coordinates and masked values, contour/fill/CI path vertices
and codes, point offsets, labels, top-axis mapping and legend meanings.
`data/figures/source/` contains the unaltered, directly associated source CSVs.

The one-time development export used the accepted V47 geometry labels, V50
phase math-font correction, V48 mechanism key and V46 resource/neural keys.
That development exporter is not needed or shipped: it depended on a private
editing-workspace history. All exported values here are static inspectable
JSON/CSV; public reproduction imports only this release's independent reader.

`figure_inventory.json` provides the original relative source-file mapping.
Scientific source programs can be run independently as described by the theory
and neural documents; replotting archived observations is distinct from
regenerating observations by simulation, training or profiling.
